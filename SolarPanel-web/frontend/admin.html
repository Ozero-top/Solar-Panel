备份与更新

🔍 在线检测更新 进后台会自动检测新版本（每小时最多一次），检测到新版时顶栏会显示「🆕 可更新」徽标；也可随时点右侧按钮立即检查。发现新版后直接点「一键下载并升级」即可，无需手动上传升级包。
系统在线升级 上传升级包（.zip）自动校验并预览变更，确认后仅应用变更文件；被替换 / 删除的原文件自动备份可回滚。当前版本 —
导出配置 下载 JSON 备份文件，包含全部分组、卡片、站点设置及所有图标 / Logo / 壁纸 / favicon 文件。
导入配置 将清空当前全部分组、卡片、站点设置和图标 / 壁纸文件，然后用备份文件恢复（用户账号不受影响）。操作前建议先导出一份当前配置。
清空恢复初始状态 将删除全部分组、卡片、自定义站点设置和图标 / 壁纸文件，恢复到刚安装时的默认状态（用户账号不受影响）。此操作不可撤销，建议先导出备份。
升级前建议先「导出配置」备份一次。
