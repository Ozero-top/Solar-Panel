🧭 基础信息

每张卡片可单独填「内网地址」（编辑卡片 → 内网地址）。此设置决定点卡片时打开哪一个。
仅 auto 模式生效。填写你在内网访问面板时用的域名或 IP，多个用英文逗号分隔。
支持精确匹配（如 test.yourdomain.com）和后缀通配（如 .yourdomain.com 匹配所有子域名）。
内置已识别 localhost、.local/.lan/.home、私网 IP 段（10.x.x.x、192.168.x.x、172.16-31.x.x），这些不用填。
控制主页展示的视图；热点新闻数据源设置在「📰 热点新闻」分区
